# visCell

**visCell** ist eine KI-gestützte Software zur automatisierten Analyse und Visualisierung
mikroskopischer Zellstrukturen auf Basis von Lichtmikroskop-Aufnahmen.

Das Projekt entsteht im Rahmen der Projektphase der Weiterbildung
zum staatlich geprüften Techniker – Fachrichtung Medizintechnik an dem Robert-Bosch-Berufskolleg in Dortmund.

---

## Projektziel

Ziel von visCell ist die Entwicklung einer portablen Windows-Anwendung, die mithilfe
von Deep-Learning-Methoden mikroskopische Zellstrukturen automatisiert erkennt,
segmentiert, visualisiert und auszählt.

Dabei kommen unter anderem folgende Verfahren zum Einsatz:

- Bildsegmentierung
- Heatmaps zur Merkmalsvisualisierung
- Distance Maps zur Objektabgrenzung
- Convolutional Neural Networks (CNN)

---

## Funktionsumfang (geplant)

- Import von Mikroskopbildern
- Automatische Bildvorverarbeitung
- KI-gestützte Zellsegmentierung
- Visualisierung von Analyseergebnissen
- Zählung von Zellstrukturen (z. B. Erythrozyten, Leukozyten, Hefezellen)
- Grafische Benutzeroberfläche (GUI)
- Export von Analyseberichten
- Hell-/Dunkelmodus

---

## Technologien

- **Programmiersprache:** Python
- **GUI:** CustomTkinter
- **Bildverarbeitung:** OpenCV, NumPy
- **KI / Deep Learning:** TensorFlow (Keras)
- **Plattform:** Windows (portable Anwendung)
