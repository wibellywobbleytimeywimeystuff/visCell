===== Repo in VS Code öffnen =====

GitHub Repo-URL kopieren

https://github.com/wibellywobbleytimeywimeystuff/visCell.git

VS Code öffnen

STRG + Umschalt + P

Git: Clone

URL einfügen

Ordner auswählen

GitHub anmelden (falls gefragt)


===== Branch wechseln (wichtig) =====

Unten links auf Branch-Namen klicken

Eigenen Branch auswählen

z. B. aust/ai, frantzke/doku, klapp/image-processing, sielhorst/gui

❌ Nicht main
❌ Nicht develop

git checkout main
git checkout sielhorst/gui

===== Arbeiten =====

IMMER git pull, bevor man auch nur irgendetwas anderes macht. 
Achtet auf die branches

Dateien bearbeiten

Nur eigene Aufgaben

Kommentarkopf erstellen!

Keine fremden Dateien anfassen

===== Änderungen speichern (Commit) =====

STRG + ö

git  add .

git commit -m "HIER DIE MESSAGE"

git push

===== Aktuellen Stand holen =====

Vor dem Arbeiten:

STRG + ö

git pull


===== Regeln =====

❌ nicht auf main
❌ nicht auf develop

✅ nur eigener Branch
✅ regelmäßig commit + push

❓ bei Fehlern: fragen
